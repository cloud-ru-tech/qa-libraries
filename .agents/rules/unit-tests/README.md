# Unit and integration testing rules

When writing or reviewing unit or integration tests, read and follow all of these documents:

- [Basic rules](basic.md): write clear, isolated tests that verify meaningful behavior.
- [Advanced rules](advanced.md): keep regression tests focused on the reported failure.
- [Matcher pattern](matcher-pattern.md): move complex assertion logic into domain-specific matchers.
